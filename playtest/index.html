Build and limitations

This first playtest is solo. Shared multiplayer, wallet-gated characters, and token spending are not enabled. Browser storage can be cleared or evicted; do not treat this world as a backup. This experimental engine requires WebGL 2, WebAssembly threads, and JavaScript Promise Integration (JSPI).
